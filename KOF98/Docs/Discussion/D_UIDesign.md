# KOF98 界面设计讨论

> **状态**：💬 讨论中

> **日期**：2026-04-06

---

## 一、概述

界面分为两大部分：**常驻 HUD** 和 **控制界面**。

- **常驻 HUD**：始终显示在游戏场景上方，提供关键战斗信息
- **控制界面**：按键触发打开，覆盖整个场景，提供游戏设置和调试功能

---

## 二、常驻 HUD

### 2.1 显示内容

| 信息 | 位置 | 说明 |
|------|------|------|
| 角色名字 | HP 条上方 | P1 左侧、P2 右侧 |
| 血量 (HP) | 顶部横条 | 数值 + 进度条，低血量变红 |
| 能量 (Power) | HP 条下方 | 细条进度条 |

### 2.2 设计要点

- 所有文字使用**正常字体风格**（非像素风格）
- 优先使用**中文标签**
- 信息层级清晰：名字 → 血量 → 能量，从上到下

---

## 三、控制界面

### 3.1 总体设计

- **非常驻**：默认隐藏，通过快捷键（如 `Tab` 或 `F1`）打开
- **覆盖场景**：打开后覆盖整个游戏场景，半透明背景
- **两列布局**（类似通用设置界面）：
  - 左侧：子 Tab 列表（垂直排列）
  - 右侧：选中 Tab 对应的内容页

### 3.2 当前需要的功能（v1）

| Tab | 功能项 | 类型 | 默认值 | 说明 |
|-----|--------|------|--------|------|
| 游戏设置 | AI 开关 | 开关按钮 | 关闭 | 控制 AI 角色是否自动行动 |
| 游戏设置 | 重新开始 | 按钮 | — | 重置场景到初始状态 |
| 游戏设置 | 自动满血复活 | 开关按钮 | 关闭 | 血量归零时自动满血复活 |

### 3.3 未来扩展功能

以下功能预留接口，后续按需实现：

| Tab | 功能项 | 类型 | 说明 |
|-----|--------|------|------|
| 角色管理 | 切换左侧角色 | 选择器 | 切换 P1 角色类型 |
| 角色管理 | 切换右侧角色 | 选择器 | 切换 P2 角色类型 |
| 角色管理 | 创建友军 | 按钮 | 在场景中添加同阵营角色 |
| 角色管理 | 创建怪物 | 按钮 | 在场景中添加敌方角色 |
| 调试选项 | 无限蓝（能量） | 开关按钮 | 能量始终满值 |
| 调试选项 | 自动复活（全局） | 开关按钮 | 所有角色死亡后自动复活 |

## 四、交互流程

```
游戏运行中
  ├─ 常驻 HUD 始终显示（角色名、血量、能量）
  │
  └─ 按下快捷键 (Tab/F1)
      ├─ 打开控制界面（覆盖场景）
      │   ├─ 左侧 Tab: [游戏设置] [角色管理] [调试选项]
      │   └─ 右侧内容: 对应 Tab 的设置项
      │
      └─ 再次按下快捷键 / ESC
          └─ 关闭控制界面，恢复游戏
```

## 五、技术要点

### 5.1 字体

- 尝试加载系统 CJK 字体（Windows/macOS/Linux 常见路径）
- 回退到 Raylib 默认字体（无中文支持时显示 ASCII）
- 仅加载 UI 实际使用的中文字符 codepoint，最小化内存占用

### 5.2 控制界面渲染

- 半透明深色背景覆盖场景
- 左侧 Tab 列表：高亮选中项
- 右侧内容：开关按钮、普通按钮、选择器等控件
- 鼠标点击 + 键盘导航

### 5.3 游戏暂停

- 控制界面打开时，游戏逻辑是否暂停？
  - **建议**：暂停（停止 `GameScene.Step()`），关闭后恢复
  - 避免在设置过程中角色被击败等意外情况
