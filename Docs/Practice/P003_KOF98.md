## 一、背景

FFVM 已完成 B 阶段（1007 assertions）和 D 阶段（分发基础设施），C 阶段（宿主集成）因 ECS 框架依赖而阻塞。
为在等待 ECS 就绪期间继续推进 FFVM 验证，创建独立的 KOF98 格斗游戏实践项目。

## 二、目标

1. 通过复刻 KOF98 核心机制，验证 FFVM 的技能脚本、AI 脚本、效果器脚本应用
2. 验证 C0 部署架构（VM 分配策略、多实例交互）的实际可行性
3. 验证 Syscall 协议（Reference/Skills/README.md）的完整性
4. 为将来的 ECS 重构建立可参照的功能基线

## 三、实践内容

- 完整游戏框架：场景、角色、技能、物理、碰撞、战斗、效果、弹幕、AI、视图
- FFVM 集成层：~40 个 Syscall + VM 实例管理桥接
- 双视图：控制台 ASCII 渲染 + Raylib 图形化渲染（碰撞框颜色可视化）
- 多目标设计考虑：目标选择、目标过滤、AOE 命中（详见总览）
- 文档：架构讨论 + 阶段计划 + 子任务追踪
