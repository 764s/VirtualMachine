# LSP 计划目录

本目录用于维护语言服务器（LSP）相关计划文档，采用三类文件命名约定。

## 命名约定

| 前缀 | 用途 | 说明 |
| --- | --- | --- |
| `Overview_` | 总览 | 单文件，T1-T6 全流程阶段、覆盖模型、进展仪表板 |
| `Step_` | 步骤实施 | 多文件，具体流程阶段的 checklist |
| `Map_` | 辅助地图 | 步骤实施的交叉验证，完整性视角，用于编写测试代码 |

## 入口

- **总览**：[Overview_LSP.md](Overview_LSP.md)（阶段定义、CFR 场景、进展仪表板、完整文件索引）
